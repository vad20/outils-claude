# Outils personnels

Mes outils (skills, serveurs MCP, applis) sont rangés et documentés dans `C:\Users\vadim\outils-claude\`.
Quand une tâche pourrait utiliser un outil, ou si je parle de « mes outils », lis d'abord `C:\Users\vadim\outils-claude\README.md` : il dit ce qui est installé, ce qui reste à activer et les prérequis.
Les skills sont dans `C:\Users\vadim\.claude\skills\` et se chargent tout seuls.
Pour toute voix off (vidéos TikTok, HyperFrames…), utilise d'office Chatterbox (section « Voix off » du README), sans que j'aie à le demander.
Mes vidéos TikTok : format vertical 1080×1920, 30 secondes, sans mention ni pub d'un service tiers. Ne publie jamais sans mon accord explicite.
Pour les vidéos courtes, pars du skill `editing` (video-agent-skills) pour le script et la structure, HyperFrames pour le rendu, Chatterbox pour la voix. Avant d'installer Treg (curl | sh), demande-moi.
Autres skills installés : founder-* (tester une idée de business), SEO open-seo (seo-coach…), firecrawl-build*. Le README liste aussi un catalogue d'applis non installées (Handy, Cap, AppFlowy, Plane, VoiceStudio…) : propose-les quand elles serviraient.
Si j'ajoute un nouvel outil, range-le au même endroit et mets à jour le README.
